# CodePilot

> 代码仓库问答 Agent —— 用自然语言问代码问题，Agent 自己搜代码、读文件、查依赖，给出答案并标注「文件:行号」。

**目标**：2027 年 2 月投递前，做成一个能演示、能讲 20 分钟、经得住三层追问的 Agent 项目。
**定位**：替代"没有实习"的简历空缺。
**技术栈**：TypeScript 全栈（Next.js + React）。
**铁律**：核心逻辑（agent loop / 检索 / 评测）自己写，AI 只写样板代码和 review。

---

## 快速开始

```bash
cp .env.example .env.local   # 填入你的 API Key
pnpm install
pnpm dev                     # http://localhost:3000
```

## 里程碑

| #  | 里程碑           | 状态 | 验收标准                                              |
| -- | ---------------- | ---- | ----------------------------------------------------- |
| M0 | 地基：能调通模型 | ✅   | 页面输入一句话，能出模型回复                          |
| M1 | 手写 agent loop  | ⬜   | 白板画出循环，解释"为什么工具结果不能直接拼进 prompt" |
| M2 | 代码索引 + 搜索  | ⬜   | 能回答"这个函数在哪定义"，给出文件:行号               |
| M3 | 混合检索         | ⬜   | 对照实验，记录 Recall 变化                            |
| M4 | 前端             | ⬜   | 流式输出 + 工具调用可视化 + 引用可跳转                |
| M5 | 工程深度         | ⬜   | 工具失败处理 + 上下文预算 + 记忆                      |
| M6 | 评测             | ⬜   | 50 条问题 + 指标 + 对照表                             |
| M7 | 上线             | ⬜   | 部署 + 开源 + README                                  |
| M8 | 表达             | ⬜   | 3/10/20 分钟讲述稿 + 3 篇博客                         |

**规则：不过验收，不进下一个。**

## 架构（随进度更新）

```
用户提问
  → 前端（React）
  → /api/chat
  → agent loop（自己写）
      → 模型决定调哪个工具
      → search_code / read_file / list_files
      → 结果回填
  → 答案 + 引用（文件:行号）
```
